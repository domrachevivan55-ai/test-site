# КБ «Энвил» — сайт kb-envil.ru

Статическая версия сайта для GitHub Pages. Исходный код (Django) хранится в приватном репозитории.

Структура:

- `index.html` — разметка
- `css/style.css` — стили
- `js/init.js`, `js/script.js` — скрипты (меню, модальное окно, анимации)
- `js/gsap.min.js`, `js/ScrollTrigger.min.js` — библиотека анимаций GSAP 3.12.5
- `fonts/` — шрифты Inter и Playfair Display
- `img/` — изображения
- `CNAME` — домен kb-envil.ru
